# 五项移动导航与图表可访问性

## 导航

窄屏底栏为总览、交易、统计、市场、更多，主页面滑动顺序与底栏一致。更多页面提供日志、系统、设置入口；次级页保留原 URL，底栏归属更多，并提供返回更多按钮。正常进入时返回原来的更多历史记录，直接访问次级页时返回更多作为后备。

宽屏左栏保留七项直接入口。页面视图按名称唯一挂载，使用 Vue Teleport 在宽窄布局的容器之间移动，保留筛选、输入和其他局部状态；页面滚动位置独立记录。离屏和隐藏容器保持不可交互，导航变更后的预加载只访问当前范围内的索引。

## K 线键盘

图表聚焦后，左右键逐根选择相邻 K 线，顶部读数和十字光标同步；选中蜡烛超出当前视野时平移到可见范围。两端限制在已有数据内，Escape 清除选中、恢复最新读数。原有价格缩放、时间缩放及复位快捷键保留。

## 历史净值测试

周期图组件测试验证 UTC 日、周、月末边界、乱序采样、采集起点过滤、缺失周期、当前期实时净值和提示金额。端到端固定数据提供非空历史净值，浏览器测试检查实际 Canvas 绘制的提示金额。金额仍以后端 UTC 周期口径归桶，用户显示时区不改变周期归属。
