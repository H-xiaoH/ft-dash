# 左侧边栏布局的页面窗口切换

- 出现左侧边栏的窗口统一使用上下切页，沿用 720 CSS px 断点；折叠屏展开与桌面保持一致。
- 动画距离取视口中可见的页面窗口高度，不随持仓数量、交易列表长度或图表内容高度变化。
- 入场前设好窗口和起始位置，短页补齐、长页裁剪；完成后释放临时高度，恢复自然内容和滚动。
- 已滚动的离场页把文档滚动位置转成窗口内部滚动，同步复位文档；内容保留原屏幕位置再开始移动，避免先闪回顶部。窗口内子项不参与压缩，结束后释放内部滚动。查询参数导航保持原有滚动行为。
- 宽布局禁用页面根节点的旧 CSS 位移动画，避免轨道完成后再次滑动；完成后根节点不得留下运行中的动画。
- 新旧页固定在同一页面轨道上，以单个动画移动整体，保持共享边缘；时长同时识别生产 CSS 中的秒和毫秒单位。
- Vue 的完成回调直接传递函数引用；正常完成、取消、resize、卸载及超时兜底统一释放动画、样式和导航等待。新导航同步解除旧 resize 保护，避免保护样式压掉新的起始位移。
- 减少动态效果设置下直接完成，不创建整页位移动画；手机底栏的横向手势与 CSS 动画保持原有行为。
- 回归覆盖触摸展开视口：持仓中短页到市场、统计到全部交易长页、动画中内容增高、总览滚到底后切页（820px 和 1280px）、完成后恢复长列表及减少动态效果。Chromium 与 WebKit 均纳入正式套件：前者检查实时播放，后者在五个固定时间点检查原生动画几何，再恢复正常播放并验证清理。

本规格替代旧桌面切页规格中的“按整页内容高度计算距离”；导航断点仍以折叠屏布局规格为准。
