# 设置页「后端」改成下拉选择

**日期：** 2026-10-31
**状态：** 已实施
**范围：** 设置页「后端」面板（`src/components/BotsPanel.vue`）

## 为什么

原来每个后端是一张卡片，卡片上有 切换 / 编辑 / 测试 / 删除 四个按钮，添加按钮在面板标题栏。后端一多，面板就是一堆重复按钮；切换和「改配置」也混在同一层，误点代价不同却很相似。

## 目标

设置 → 后端 原来是「卡片列表 + 添加按钮 + 每行 切换/编辑/测试/删除」。改成：
一个下拉选后端，最后一项「管理后端」展开添加/修改/删除。

## 验收标准

- 面板顶部只有一个下拉（`FilterMenu`），按钮上只显示**后端名称 + 暗色 API 地址**，不加「后端」前缀；选项 = 已保存的后端 + 最后一项「管理后端」。面板标题与 `bots.*` 文案一律用「后端」（配置实体），而「机器人」只指真正在跑的那个进程。
- 按钮和每个选项里，后端名称前都有状态灯：正常绿、正在请求或首次连接中黄、不可用红、本应用没在轮询的后端灰。灯跟着轮询节奏刷新。
- 选中某个后端 = 切换到它（沿用 `bot.switchBot`，需要密码时在下方出现密码提示）。
- 选「管理后端」= 不切换，展开管理区；再点「关闭」收起，并清掉未保存的表单与删除确认。
- 管理区里有：每行 编辑 / 测试连接 / 删除，底部 添加后端，点编辑或添加后出现原来的表单。
- 删除确认仍是行内确认（`InlineConfirm`），不是弹窗。
- 独立的那行后端摘要（`.bots__meta`）取消：名称与地址已经在按钮上。
- 面板内顺序：下拉 → 管理区 → 后端控制（`ControlsPanel`）→ 记住凭据。后端控制从原来的独立面板搬进来，写操作语义不变。
- 设置页不再有「推送」面板：WebSocket 常开、鉴权走自动 JWT，`ws_token` 只在后端编辑器里填。
- 与「推送」相关的界面一并移除：系统页的「实时事件」面板（`EventTape`）、顶栏的推送状态灯、系统页的连接状态里那两行推送信息、以及推送断开时的横幅。事件数据仍由 store 收集，但界面不再展示。
- 切换后端会重建 `page-track`（有 key），所以管理区随之收起——这是既有行为。
- 中英文案同步：新增 `bots.select` / `bots.manage`，删掉不再使用的 `bots.switchTo`。
- 界面文案统一用「后端」：配置实体（`bots.*`）、写操作（`actions.*` → 后端控制）、心跳与停止告警、连接页标题都算。只有 Freqtrade 自己的术语（api_server、strategy）和文档里的历史说法保留「机器人」。

## 不做什么

- 不改成弹窗：管理区就展开在面板里（后端控制也一样），页面本身可滚动，不需要抢焦点、上锁、处理 Esc。
- 不动切换机器人的语义：切换仍然重建 `page-track`（`App.vue` 上以 activeBotId 为 key），因此管理区会随之收起。
- 不新增「同时轮询多个机器人」之类的并行能力。
