# 复审整改与列表性能

## 数据边界与状态

- 交易解析入口校验 `enter_tag` 为字符串、null 或缺省，非法类型报告 parse 错误。
- 获取浏览器存储对象不再尝试写探测键；读取、写入和删除分别处理异常，存储配额耗尽也可删除凭据。
- 推送先解析为 unknown，再验证消息 type 与可选对象 data；非法帧忽略，后续合法帧继续处理。
- 市场 K 线的加载状态跟随当前选择，缓存命中也会退出加载状态；旧请求不得覆盖当前状态。
- 周期图实时订阅减少动态效果偏好。
- 连接测试按后端 ID 记录等待状态并防重入。连接身份变化、删除或组件卸载时取消请求；旧结果不能写回。

## 列表与格式化

- 交易分页保留原排序、筛选与分页行为；“全部”使用 Vuetify 虚拟表格，保持完整数据可滚动访问、交易详情入口与 CSV 导出。
- 日期格式器按语言、时区和格式选项复用，最多保留 64 项，按最近使用顺序淘汰；日期输出保持原样。

## 组件边界

- `DashboardPeriod`：总览周期选择、图表与日期明细展示；周期通过 v-model 与页面同步。
- `MarketPairLists`：市场名单标签、筛选与展示；数据由 props 输入，选择及写操作通过事件交回页面。
- `TradeTable` / `TradeTableRow`：交易表格的分页／虚拟渲染与行展示；筛选数据、CSV、路由和写操作留在页面。

## 验收

为非法数据、存储满、推送帧、请求竞态、媒体查询变化和格式器缓存添加回归测试；大列表浏览器测试确认 DOM 行数有界且末行可访问。执行项目完整验证序列并独立复审。
