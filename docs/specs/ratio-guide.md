# 统计页比值说明弹窗

**日期：** 2026-10-30
**状态：** 已实施
**范围：** 统计页两块风险磁贴（`夏普 / SQN`、`索提诺 / Calmar`）与其说明弹窗

## 目标

统计页把夏普、索提诺、SQN、Calmar 四个数字直接摆在磁贴上，但没告诉操作者「多高算好」。改动只加一层解释，不动数据、不动接口、不动指标算法。

四块磁贴各自独立：点「夏普」只看夏普的说明，点「Calmar」只看 Calmar 的说明。

## 验收标准

- `夏普 / SQN` 与 `索提诺 / Calmar` 两块磁贴可点（根元素是 `<button type="button">`，右上角一个 ⓘ），其余磁贴仍是 `<div>`。
- 点哪一块只解释哪一个：弹窗标题就是该指标名（`夏普（Sharpe）`、`SQN（系统质量数）`、`索提诺（Sortino）`、`Calmar（收益回撤比）`），正文是它自己的「一句白话 + 一行读数分档 + 一句样本提醒」。不把四个堆在同一个弹窗里。
- 分档数字只在 `src/lib/ratios.ts` 的 `RATIO_BANDS` 写一次：磁贴按它上色，文案用 `{weak}` / `{good}` 插值，两边不会各说各话。
- 分档口径：夏普 <1 不划算、1–2 合格、2–3 很好、3+ 优秀；索提诺 <1 回撤吃掉收益、2+ 好、3+ 优秀；SQN 按 Van Tharp 1.6 以下 / 1.6–1.9 / 2.0–2.4 / 2.5–2.9 / 3.0–5.0 / 5–7 / 7+；Calmar <0.5 / 0.5–1 / 1–3 / 3+。
- 每块都带同一句提醒：比值适合同自己比、样本少于 30 笔意义不大。
- 弹窗可 Esc、点遮罩、关闭按钮三种方式退出；退出后焦点回到打开它的那块磁贴；弹窗打开时页面 `inert`。
- 手机上说明改单列（宽度 ≤560px），弹窗自身可滚动，不撑破视口。
- 中英文案同步，`tests/i18n.spec.ts` 通过。

## 不做什么

- 不加「指标术语」独立页面或帮助中心。
- 不在磁贴上直接写分档，磁贴仍只放数字。
- 不引图表库，也不改 Freqtrade 的指标计算。
