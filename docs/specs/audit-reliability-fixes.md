# 审计后的运行时可靠性与 Safari 基础样式修复

日期：2026-11-01。范围为已有数据层、视图和样式的局部修复，不增加依赖或后端。

## 行为与验收标准

- 写入口在发送请求时统一检查控制开关、风险确认、在线状态、核心与交易数据就绪、快照新鲜度及写锁。先前打开的确认框也不能绕过失效的数据状态。
- 后台健康请求失败时仍用最后一次心跳判断静默，超过30秒通知一次，恢复后重新允许告警；旧会话响应不影响当前告警，失败的健康探测撤销核心就绪。
- 市场页成功加载后30秒刷新K线，失败10秒重试；仅当前可见页面请求，离开、后台和卸载清理定时器，返回时更新过期缓存，同一交易对请求不堆积。
- 连接页与后端编辑器把URL校验、探测和保存纳入异常处理，始终恢复提交状态。非法地址显示配置错误，修正后可重新提交。
- 无已加载明细的交易对手续费与成交额为未知值，显示“—”。交易对表说明胜率、时长、手续费和成交额仅基于已加载窗口；累计笔数和盈亏仍取服务端总值。
- 成交按K线时间区间匹配，左闭右开，最后一根以timeframe_ms界定；缺失区间及窗口外不标记，保留多空方向。
- Safari15.5使用基础颜色、WebKit背景模糊前缀、裁剪和媒体查询兜底。color-mix增强样式放在显式正向@supports内，紧随基础规则以保留层叠顺序。旧浏览器不依赖含var的无效声明回退。
- 保留事件历史这一既有产品决定，不改变策略、账户配置或现有仓位。

## 验证范围

单元/组件测试覆盖执行门禁、后台失败与恢复、非法URL重试、K线刷新与可见性/卸载、未知统计和成交区间。端到端新增测试将color-mix替换为未知函数并保留var，禁用容器查询，验证底栏、总览列和弹窗基础背景。

独立复审指出CSS计算阶段失效后，先以加强用例复现失败，再用@supports隔离修复；复核未发现新的Critical/Important。

用户明确确认的模拟盘完成开仓到市价平仓验证；仅处理测试范围内的交易，核对交易已关闭。具体交易参数和账户信息已移除。不把dry_run=false自行等同于交易所真实资金环境。

物理iPhone与Safari15.5的安装、安全区、旋转、离线恢复仍需另行真机验证；CSS功能禁用测试不等同于旧版物理设备验证。
