# 市场测试稳定性与警告清理

## 行为与边界

- K 线全部可见时，时间范围滑块最大值为精确的 0，滑块不可滚动。
- 图表库返回的逻辑范围可能带有浮点尾差。剩余范围不超过 `Number.EPSILON × max(1, K线数量) × 4` 时归零；正常小数范围保留。
- 组件测试通过图表范围订阅回调复现尾差，并验证 0.25 根 K 线的真实剩余范围仍然有效。
- 手机交易对弹层边界测试先等待页面布局稳定，再打开菜单测量，四边边界断言不放宽。
- 页面所有 `VRow dense` 改用 `density="compact"`。
- 市场页组件测试显式声明 `/elsewhere` 路由，以支持离开、返回与缓存测试；不屏蔽路由警告。

## 验收方法

运行类型检查、单元与组件测试、代码和格式检查、生产构建及完整端到端测试。对市场交易对菜单边界与图表缩放用例进行重复运行，确认原始失败不再出现。
