# MD3 控件一致性与可读性

## 控件与文字

- 工具栏按钮、分段选项和排序组统一为 36 CSS px 高，文字使用 Vuetify 默认的 14px；图标按钮与同组控件等高。
- 后端地址需要换行时允许按钮自然增高，宽窄屏均完整显示地址。
- 移除覆盖 Vuetify 层叠样式的全局控件文字重置，由组件自身提供字号和主题前景色。浅色主操作和危险操作分别使用深色 `on-primary`、`on-error`。
- 输入框使用 Vuetify 的字段焦点边框，不再给内部输入节点叠加圆角焦点阴影。自定义滚动区仍保留可见焦点。
- 后端下拉标题使用带内边距的卡片标题，避免列表标题在列表容器外失去对齐。

## 交易对

总览、交易和统计统一为无胶囊底色的数据文字。总览和交易保留既有点击入口，统计保持普通文字；方向信息不变。

## K 线

无数据时显示原尺寸的灰色占位块，移除空数据解释文字。空响应与失败均每秒重试，仅在市场页可见时执行；正常响应仍每 30 秒刷新。后端没有返回行情时，前端不会生成替代 K 线。

## 验收覆盖

- 组件测试覆盖空 K 线响应的一秒重试与无文字占位。
- 浏览器测试覆盖 390、693、954px 工具栏高度、无底色交易对、后端编辑输入焦点、弹窗与保存按钮对比度。
- 既有后端选择测试继续覆盖 1440、320px 长地址完整显示。
- 不提交、不推送。
