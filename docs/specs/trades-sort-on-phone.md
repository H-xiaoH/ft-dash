# 交易列表在手机上也能排序

**日期：** 2026-10-30
**状态：** 已实施
**范围：** 交易页工具条（手机宽度）

## 问题

排序逻辑本来就是共用的：`sortKey` / `sortDir`、`toggleSort()`、`rows` 的排序、以及「换排序回第一页」的 watcher。手机上排不了序，唯一原因是入口长在 `u-desktop-only` 表格的列头里。

## 验收标准

- `≤720px` 时工具条多出两个控件：**排序**下拉（交易对 / 投入 / 盈亏 / 持仓时长 / 开仓时间）与**方向**按钮（`chevronUp` / `chevronDown`，`aria-label` 为「升序 / 降序」）。
- `>720px` 时这两个控件隐藏，桌面继续用列头排序，行为不变。
- 选字段走 `toggleSort()`，方向规则与列头一致（交易对升序，其余降序）；方向按钮只翻转，不重开菜单。
- 排序作用于已加载的数据（≤300 条），不新增请求；换排序回到第一页（沿用现有 watcher）。
- 手机工具条一行放得下五个控件，不产生横向溢出：导出按钮在手机只留图标（`aria-label` 与 `title` 仍是「导出 CSV」），工具条间距在 `≤720px` 收紧到 4px。
- 中英文案同步（`trades.sort` / `trades.sortAsc` / `trades.sortDesc`）。

## 不做什么

- 不改统计页、市场页的排序（统计页的每对表格有同样的缺口，需要时按同一套做法再做一次）。
- 不加「点同一项换个方向」这种隐藏手势，方向始终可见。
- 不动服务端排序或接口参数。
