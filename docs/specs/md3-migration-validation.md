# MD3 迁移验证修复

## 目标与边界

修复组件库迁移后的验证失败，保留连接、权限确认、排序、分页、导航、图表与滚动行为。基础界面使用 Vuetify 4 / MD3，图表和切页继续使用已选定的库；不增加依赖、后端或第三方 API。

## 实现

- Vitest 接入 Vuetify 自动导入和浏览器环境补齐。图表单元测试验证数据、价格线、标记和缩放接口，真实 Canvas 绘制及手势由浏览器测试覆盖。
- 将旧 SVG、手写动画和旧控件选择器断言迁移到现有组件。几何测量等待字体、主布局、切页和菜单动画完成，拖动测试等待实际激活及预览状态。
- 修复导航、日志的 ARIA 结构、菜单标题对比度和系统页滚动区域的键盘入口；导航保留链接语义。
- 指标按钮显式占满列宽；提示条恢复右下角定位并避让底栏。
- 弹窗通过 Vuetify 的 activator 恢复焦点；交易详情的历史记录由路由处理。详情在历史记录写入后显示，独立窗口深链在已有页面实例上也会补齐列表返回层级。
- 宽窄屏切换取消当前 Swiper 手势，更新方向及触摸开关，保留页面实例、筛选和滚动位置。
- 后端排序使用 SortableJS 的拖动实现，保留长按、键盘调整与顺序保存；行内操作按钮高度一致。
- ECharts 按核心、系列与渲染器拆分，消除构建分包大小警告。
