# 窄屏详情、搜索与页面过渡

- 交易详情正文负责纵向滚动。订单卡按内容撑开，窄屏仍可横向滚动订单表。多笔订单场景须能滚到最后一笔，背景交易页保持原位置。
- 交易、统计、市场和日志共用搜索控件。展开时提示文字留在框内，输入框保留可供辅助技术读取的名称。关闭按钮始终可用，点击关闭或按 Escape 清空搜索并收起。点到外部时，空搜索收起，已有关键词和筛选结果保留，焦点留在外部控件。
- 总览周期图使用 HTML 提示框，限制宽度和位置。空间不足时，盈亏百分比可整体换行。窄屏验收覆盖 320 px 与 479 px 的中英文提示框，以及靠近图表两端的长负值。
- 窄屏的「更多」列表和日志、系统、设置共用一个 Swiper 滑页。目标内容挂载后进入，子页从右侧滑入，列表向左淡出，返回反向播放。过渡为 220 ms，减少动态效果时直接切换。各页保留筛选状态与独立滚动位置。
