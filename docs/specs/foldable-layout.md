# 折叠屏窗口布局与手势
- 主布局在720 CSS px切换：小于720底栏/横向切页，720起左栏/上下切页。
- 交易列表、排序控件和表格仍以900px空间判断，设置列数等内容断点保持独立。
- 抽屉、提示条避让、顶栏密度与主导航同步，不按型号或触摸能力判定布局。
- 宽屏不抢占横向触摸作为切页；内容上下滚动不变。
- touchcancel、resize（含折叠/旋转）、离开页面/卸载清理拖动，取消等待中的手势提交，不能留下offset、handoff或滚轮累计。
- 桌面动画遇窗口变化立即终止位移，清理临时高度及导航等待；下次切页使用新尺寸。
- 验证719/720/721及768/820/900/901/1024布局、拖动取消、提交中折叠、跨断点复位与手机/桌面原导航测试。
