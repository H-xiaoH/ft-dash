# 审计修复与界面操作补充

- 「记住凭据」跨标签页同步。关闭后清除长期存储的密码和推送令牌。新版标签页继续使用各自的当前会话，连接尚未完成时也保留已读取的凭据和所选后端。新版只迁移一次旧存储，启动和收到旧键写入事件时会清理旧键。升级后刷新或关闭仍在运行旧代码的标签页或 PWA 窗口，停止旧代码自行写入。普通保存和切换不会重新开启记忆。
- 可用余额取投入钱包的 `bot_owned`。优先使用配置提供的代理币种，否则按结算币识别钱包。明确的零值正常显示，无法确定时显示 `—`。
- 进入总览、总览恢复可见、可见总览每 60 秒及手动刷新时请求历史净值。同一后端的重叠请求合并，失败保留已有历史。历史净值接口单独返回 401 时，总览继续显示，余额与交易仍可刷新。当前净值点跟随常规余额。移除未使用的 `/profit_all`。
- CSV 在统一导出入口保护可被解释为公式的文本，盈亏百分比以可参与计算的数字导出。
- 「管理后端」是下拉菜单底部的独立动作。顶栏传递一次打开指令，由设置面板负责定位和焦点。切换后端后收起管理区，两个入口只反馈最新的切换结果。关闭密码弹窗或取消设置页内的密码提示后，焦点返回可见控件。缺少密码的后端仍做公开探测，可达时标记为尚未验证凭据。
- 后端排序支持把手菜单的上移和下移、拖动和方向键。周期明细与图表使用同一份净值读数。K 线支持点按缩放价格轴和时间轴。日志滚离顶部或关闭自动跟随后，保留当前显示的记录。自动滚动开启时回到顶部即恢复，也可以随时点击「回到最新」恢复。
